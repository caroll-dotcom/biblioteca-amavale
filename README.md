# Biblioteca Amavale

Protótipo da Biblioteca Autônoma da Amavale — Associação de Moradores do Vale das Videiras.

Objetivo: permitir consulta ao catálogo, autoempréstimo e autodevolução de livros pelo celular, com identificação de estantes e prateleiras por QR Code.

Este repositório começa com uma versão demonstrativa para apresentação e validação do fluxo antes da implementação do banco de dados real.
